# Paquete de distribución

El único dashboard generado para consulta es **`../index.html`**, en la raíz del repositorio. Se abre directamente con un navegador y es el mismo archivo que se publica.

`Dashboard_para_publicar.zip` contiene ese mismo HTML y la licencia de la tipografía. No requiere archivos de datos externos, Python ni conexión a internet para la consulta.

Las fuentes editables están en `02_codigo/dashboard`. Use `ACTUALIZAR_DASHBOARD.cmd` para reconstruir el HTML y este paquete. Para cambios de insumos o umbrales, use `EJECUTAR_ANALISIS.cmd`.
